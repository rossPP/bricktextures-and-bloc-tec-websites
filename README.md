# Websites Workspace

This workspace holds the website build and planning material for the Brick Textures launch.

## Structure

- `bricktextures-site` - React + Vite site for `bricktextures.com`.
- `bloc-tec-site` - React + Vite site for `bloc-tec.com`.
- `planning` - launch strategy, copy, and commercial model notes.
- `assets/shared` - shared brand assets used by both sites.
- `assets/bricktextures` - image assets dedicated to Brick Textures.
- `assets/bloc-tec` - image assets dedicated to bloc-tec.com.

## Current Build Direction

- Launch focus remains `bricktextures.com` and `bloc-tec.com` in parallel.
- Brand presentation: `Brick Textures by BLOC-TEC`.
- Hub URL currently points to the live account path and opens in a new tab.
- Mobile-friendly responsive pages are included in v1 for both sites.
