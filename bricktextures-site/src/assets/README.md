# Page image drop folders

Drop new images into the folder for that page. Keep each page’s assets separate.

| Folder | Page |
|--------|------|
| `colours/red` | Red and orange colour guide |
| `colours/buff` | Buff colour guide |
| `colours/brown` | Brown colour guide |
| `colours/neutral` | Neutral colour guide |
| `finishes/smooth` | Smooth finish |
| `finishes/glazed` | Glazed finish |
| `finishes/tumbled` | Tumbled finish |
| `finishes/traditional` | Traditional finish |
| `finishes/wirecut` | Wirecut finish |
| `formats/standard` | Standard size |
| `formats/imperial` | Imperial size |
| `formats/linear` | Linear size |
| `formats` (root) | Size hub card images only (`metric.webp`, `imperial.webp`, `linear.webp`) |
| `mortar` | Mortar colour page |
| `joint-sizes` | Joint size page |
| `bonds/classic` | Classic bonds — Swanage Handmade Restoration Red examples |
| `bonds/modern` | Modern bonds — Throckley Smooth Red examples |
| `bonds/traditional` | Traditional bonds — Oud Maasland examples |
| `clay-vs-concrete` | Clay vs concrete |
| `brick-blending` | Tools — brick blending |
| `seamless-textures` | Tools — seamless textures (joint/layout/blend pairs + tile size pair) |
| `share-design` | Tools — share design (example HTML + preview image) |

After dropping files, say which page they belong to and they can be cropped, converted and wired in.
