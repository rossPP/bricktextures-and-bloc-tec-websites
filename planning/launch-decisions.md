# Launch Decisions

## Domains

- `bricktextures.com` is the priority launch website and public-facing hub brand.
- `bloc-tec.com` remains the company/app/business-information domain.
- Integration implementation guidance/options should live on `bloc-tec.com`, not on the initial `bricktextures.com` marketing experience.

## Naming

- Account slug to lock in: `bricktextures`.
- Public display name: `Brick Textures`.
- Branded attribution: `Brick Textures by bloc-tec`.
- Rename timing: keep `demo` during build phase, then rename to `bricktextures` when launch-ready.
- Existing share-link compatibility is not a launch blocker for this transition.

## Theme and Typography

- Primary colour: `#008272`.
- Text colour: `#0b0b0b`.
- Background: `#ffffff`.
- Font family: `Segoe UI` style stack.
- Light-first design for accurate material colour presentation.
- No switchable dark mode in v1.

## Commercial Model

- Hub inclusion can be free where suitable assets/data are supplied and capacity allows.
- Free hub inclusion does not include rights for manufacturer website use.
- Manufacturer website use is paid.
- Modules such as blending and textures are visible on the hub but paid add-ons for website use.
- Assisted onboarding and photography support are paid where extra manual work is required.

## Pricing Visibility

- Launch with clear commercial structure, not full public prices.
- Add post-launch pricing transparency when packages stabilize.

## Website Focus Sequence

- Build and refine `bricktextures.com` first (homepage + immediate hub interaction + manufacturer page).
- Start `bloc-tec.com` basics after the Brick Textures launch messaging is stable.
