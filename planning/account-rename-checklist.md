# Account Rename Checklist (`demo` -> `bricktextures`)

Use this when you are ready to switch the live hub identity.

## Scope

- Current account path: `/account/demo/`
- Target account path: `/account/bricktextures/`
- Decision note: preserving old share links is not required for launch.

## Steps

1. Duplicate or rename the account file from `demo` to `bricktextures` in the account data source.
2. Update account display title and branding labels to `Brick Textures`.
3. Update website hub links from `/account/demo/` to `/account/bricktextures/`.
4. Smoke test key hub routes (home, category, product, viewer, share button).
5. Verify manufacturer and homepage CTAs open the correct hub path.
6. Announce the new canonical hub URL in launch comms.
